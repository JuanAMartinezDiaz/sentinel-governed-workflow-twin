# Contributing

This repository is a public reference project for governed agentic workflow execution.

Contributions are welcome when they improve:

- deterministic governance behavior
- testability
- evidence quality
- workflow measurement
- synthetic examples
- security of the reference boundary
- clarity of documentation

Do not submit proprietary employer/client material, credentials, production data, or confidential architecture.

For behavior changes, include or update tests that demonstrate the intended governance property.
